# Gocciolo

Un piccolo compagno per Windows che ti ricorda di bere. Prenditi cura di Gocciolo con un bicchiere d'acqua alla volta.

## Come funziona

- Ti avvisa ogni 45 minuti con un promemoria nell'area di notifica di Windows.
- Premi **Ho bevuto** dopo aver bevuto: il timer riparte e il morale di Gocciolo torna al massimo.
- Se passa troppo tempo, il morale scende gradualmente.
- Chiudendo la finestra, l'app resta attiva nell'area di notifica. Per uscire, scegli **Esci** dal menu dell'icona.

## Installazione

Scarica **Gocciolo-Setup.exe** dalla sezione **Releases** di questo repository e avvia l'installer.
Gocciolo è pensato per Windows a 64 bit. Avvia l'app dopo l'installazione per ricevere i promemoria.
